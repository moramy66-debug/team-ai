## 2) المطلوب
أ) ملف بيانات جديد: data/code-library.json. مصفوفة بنود، كل بند فيه الحقول دي بالظبط:
   id، code (sbc401 أو sec_dps أو sec_dc ... إلخ)، topic (عنوان قصير بالعربي)، text (شرح مقروء بالعربي المصري المهني، مصطلحات الهندسة بالإنجليزي)، clause (رقم البند أو null)، source_url (رابط عام تم فتحه فعلًا أو null)، source_note (وصف المصدر)، status، checked_on (تاريخ المراجعة).
   قيم status: verified_mirror (مأخوذ من صفحة عامة مفتوحة وقريتها) / verified_secondary (مصدر ثانوي) / needs_review (من الذاكرة أو غير مؤكد).
ب) المحتوى المطلوب (قدر المستطاع من مصادر عامة): متطلبات عملية في SBC 401 (voltage drop، حماية، تأريض، كابلات، لوحات) ومتطلبات SEC المنشورة علنًا (Distribution Code وDPS وأي مواصفات منشورة على موقع SEC). المستخدم عنده بالفعل ملاحظات في الـ 14 كود الحالية، فاقراها وتجنب التكرار وأي تعارض معاها. لو لقيت تعارض اكتبه في التقرير ومتصلحوش بنفسك.
ج) واجهة جديدة في ملف جديد js/code-library.js: لازم يتلف كله بـ IIFE: (function(){'use strict'; ... })(); ومفيش أي تعريف top-level. لما التطبيق يفتح بتضيف زرار "Code Ref" مكان مناسب (ما تلمسش زراير topbar الأساسية، استخدم قايمة More اللي موجودة في js/ui-tidy.js أو بانل مكتبة الأكواد) بيفتح عرض فيه: بحث نصي (ضيف normalization عربي بسيط)، فلتر بالكود، قايمة بنود قابلة للفتح، وبادج لحالة كل بند بألوان واضحة، ورابط المصدر لو موجود. الأزرار والعناصر 44px على الأقل، مفيش horizontal overflow عند 390px، مفيش emoji (SVG بس)، ومحتوى النص بيتعرض بـ textContent مش innerHTML.
