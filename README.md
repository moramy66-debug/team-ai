# Team AI — منصة ذكاء اصطناعي متعددة الوكلاء (Multi-Agent AI Workspace)

تطبيق ويب تقدمي (**PWA**) باللغة العربية (`RTL`) لإدارة وتنسيق مهام الذكاء الاصطناعي عبر عدة وكلاء ومزودين، يعمل مباشرة في المتصفح بدون الحاجة إلى خادم خلفي أو أدوات بناء (**Zero-Build Vanilla HTML/CSS/JS**).

## أبرز المميزات
- **تعدد المزودين والوكلاء:** دعم Google Gemini، وGroq (نماذج GPT-OSS وQwen 3.8 27B)، وOpenRouter، وOpenAI، وAnthropic Claude.
- **تنسيق المهام والمرونة:** تنفيذ المهام على خطوات متسلسلة مع نقاط استعادة (`RCK.steps`) وتحويل تلقائي لوكيل بديل (`stepF0`) عند تعثر أي مزود.
- **معالجة الملفات محلياً:** استخراج النصوص من PDF عبر `pdf.js`، وقراءة جداول Excel وإعادة حساب صيغها عبر `XLSX`.
- **تصدير ومشاركة:** تصدير النتائج بصيغ PDF وExcel مع صورة توقيع، وإرسال النتائج عبر البريد الإلكتروني (EmailJS).
- **مكتبة الأكواد الهندسية:** إدارة الأكواد الهندسية (`SBC 401`, `IEC 60364`, `SEC DPS`).
- **العمل دون اتصال (PWA):** قابل للتثبيت عبر `manifest.webmanifest` و`sw.js`.

## التشغيل المحلي
```bash
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`.
